# Zinc 0.11.1

This patch adds a guided Linux AMD64 installer and streamlined schema v4 documentation.
See the [quickstart](../quickstart.md) and [changelog](../../CHANGELOG.md#0111---2026-10-17).

The installer verifies all five binaries against the release checksums and reported
versions before replacing tools individually. It configures the supported shell's PATH,
downloads the matching release's offline example, resolves its image pin, displays the
YAML and asks before launching. Existing example YAML is preserved.

The installer requires HTTPS access and standard Linux utilities. Example image resolution
requires rootless Podman; launching additionally requires a desktop terminal.
Use `--no-example` to install only the tools.

Schema v4 and the [0.11.0 upgrade requirements](0.11.0.md#upgrade-requirements) still apply.
